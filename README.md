# Cybersecurity Home Lab

Hands-on labs I built while transitioning into identity and access management (IAM) and security operations, after 10 years of regulatory compliance work.

## Labs

| Lab | What it covers | Tools |
|---|---|---|
| [IAM: Active Directory & Joiner-Mover-Leaver](iam-active-directory/) | Domain controller from scratch, RBAC group design, PowerShell automation of onboarding, role change, and offboarding, access verification | Windows Server 2022, Active Directory, DNS, PowerShell |
| SOC: Sysmon + Splunk *(coming soon)* | Endpoint telemetry forwarded to a SIEM, detection queries mapped to MITRE ATT&CK | Sysmon, Splunk, Kali Linux |

## Skills

- **Identity & access:** Active Directory, OU and group design, RBAC, least privilege, Joiner-Mover-Leaver, access reviews
- **Automation:** PowerShell (ActiveDirectory module, CSV-driven bulk changes)
- **Security monitoring:** Sysmon, Splunk SPL, MITRE ATT&CK
- **Infrastructure:** VirtualBox, Windows Server, DNS, TCP/IP
